# 날씨 데이터 분석 및 풍속 예측

## 1. 프로젝트 소개 및 제작 목적

이 프로젝트는 대학교 **「코딩과응용」 과목의 날씨 데이터 분석 과제**입니다. 2023년부터 2024년까지의 시간별 관측 자료를 점검하고, 관측 시각을 정리한 뒤, 과거 풍속과 기온·습도를 이용해 1시간 뒤 풍속을 예측합니다.

기준 모델(Persistence)과 선형 회귀(Linear Regression)의 예측 오차를 비교하고, 2025년 1월 1일 00시의 풍속을 예측하는 과정을 포함합니다.

## 2. 사용 데이터와 출처

- 원본 파일: `asos_108_2023_2024.csv`
- 원본 데이터 행 수: **17,509행**
- 관측 기간: **2023-01-01 00:00 ~ 2024-12-31 23:00**
- 원본 열:
  - `datetime`: 관측 시각
  - `temperature_C`: 기온(°C)
  - `humidity_pct`: 습도(%)
  - `wind_speed_ms`: 풍속(m/s)

프로젝트에 포함된 원본 파일은 `asos_108_2023_2024.csv`입니다. 다만 현재 프로젝트 파일에는 데이터 제공 기관, 다운로드 URL, 라이선스 또는 출처 인용 정보가 기록되어 있지 않습니다. 따라서 이 README는 파일명이나 열 이름만으로 제공처를 단정하지 않습니다. 과제 제출 시 원본을 받은 웹사이트나 기관을 확인해 출처를 보완하는 것이 좋습니다.

## 3. 개발 환경 및 사용 언어

프로젝트 파일을 실행·확인한 환경:

- 운영체제: macOS
- Python: **3.14.7**
- pandas: **3.0.6**
- scikit-learn: **1.9.1**
- matplotlib: **3.11.2**

사용 언어는 Python입니다. 날짜 및 표 형식 데이터 처리에는 pandas, 선형 회귀 모델과 평가에는 scikit-learn, 그래프 작성에는 matplotlib를 사용합니다. 프로젝트 최상위 폴더에 별도의 `requirements.txt`는 없습니다.

## 4. Python 파일의 역할

| 파일 | 역할 |
|---|---|
| `check_data.py` | 원본 CSV를 읽어 행 수, 관측 기간, 중복 시각, 1시간 기준 누락 시각 및 풍속·기온·습도 빈칸을 점검합니다. |
| `prepare_hourly_data.py` | 원본 데이터에 2023-01-01 00시부터 2024-12-31 23시까지의 시간 목록을 적용합니다. 누락 시각을 추가하되 관측값은 보간하거나 임의로 채우지 않고 `hourly_data.csv`로 저장합니다. |
| `create_wind_dataset.py` | 현재 풍속, 1·2시간 전 풍속, 현재 기온·습도와 1시간 뒤 풍속을 시간 기준으로 연결해 학습용 데이터를 만듭니다. |
| `split_wind_dataset.py` | `target_time`을 기준으로 학습 구간과 테스트 구간을 나누고 각각 CSV 파일로 저장합니다. |
| `evaluate_models.py` | 학습 데이터로 선형 회귀를 학습하고, 테스트 데이터에서 Persistence 기준 모델과 선형 회귀의 MAE를 비교합니다. 두 모델의 테스트 예측은 `predictions.csv`로 저장합니다. |
| `plot_predictions.py` | `predictions.csv`를 이용해 2024년 12월 1~7일의 실제 풍속 및 두 모델 예측 그래프를 만듭니다. MAE는 그래프 구간이 아니라 12월 전체 테스트 데이터로 계산합니다. |
| `predict_next_hour.py` | 2024-12-31 23시까지의 관측 입력값을 확인하고, 학습 데이터만으로 학습한 선형 회귀 모델로 2025-01-01 00시 풍속을 예측합니다. |

## 5. 데이터 전처리 및 분석 과정

1. `check_data.py`로 원본의 행 수와 관측 기간, 중복·누락 시각, 주요 기상 변수의 결측을 확인합니다.
2. 원본에는 **1시간 기준 누락 시각 35개**가 있습니다. 풍속에는 기존 결측값 33개가 있고, 기온·습도에는 원본 결측이 없습니다.
3. `prepare_hourly_data.py`는 정해진 관측 기간의 모든 시간을 생성해 누락 시각을 추가합니다. 추가된 행의 기상값은 빈칸으로 유지하며 기존 풍속 결측도 채우지 않습니다.
4. `create_wind_dataset.py`는 각 `prediction_time`을 기준으로 다음 입력 변수를 시간값에 맞춰 구성합니다.
   - 현재 풍속: `wind_speed_ms`
   - 1시간 전 풍속: `wind_speed_1h_ago_ms`
   - 2시간 전 풍속: `wind_speed_2h_ago_ms`
   - 현재 기온: `temperature_C`
   - 현재 습도: `humidity_pct`
   - 정답: 정확히 1시간 뒤의 풍속, `target_wind_speed_ms`
5. 입력 변수 또는 정답이 비어 있는 행은 제거합니다. 결측값을 임의로 대체하지 않습니다.
6. `evaluate_models.py`는 Persistence와 Linear Regression의 예측을 같은 테스트 행에 적용하고 MAE(평균절대오차)를 계산합니다. 선형 회귀 예측값은 음수일 경우 0으로 제한합니다.
7. `plot_predictions.py`는 실제 풍속과 두 예측 결과를 그래프로 비교합니다. `predict_next_hour.py`는 최신 관측값을 사용해 다음 시각의 풍속을 예측합니다.

## 6. 학습 데이터와 테스트 데이터 분리

`split_wind_dataset.py`는 데이터를 무작위로 섞지 않고 `target_time`의 기간으로 분리합니다.

- 학습 데이터: **2023-01-01 00:00 ~ 2024-11-30 23:00**
  - 결과 파일: `train_dataset.csv`
  - 실제 행 수: **16,720행**
- 테스트 데이터: **2024-12-01 00:00 ~ 2024-12-31 23:00**
  - 결과 파일: `test_dataset.csv`
  - 실제 행 수: **744행**

모델 평가는 `train_dataset.csv`만 학습에 사용하고 `test_dataset.csv`는 평가에만 사용합니다. `predict_next_hour.py` 역시 `train_dataset.csv`의 `target_time`이 2024-11-30 23시를 넘지 않는지 확인한 다음 학습합니다.

## 7. 설치 및 실행 방법

터미널에서 프로젝트 최상위 폴더로 이동합니다.

```bash
cd ~/Desktop/weather-data-analysis
```

필요한 라이브러리를 설치합니다.

```bash
python3 -m pip install pandas scikit-learn matplotlib
```

처음부터 순서대로 실행하려면 아래 명령을 차례로 입력합니다.

```bash
python3 check_data.py
python3 prepare_hourly_data.py
python3 create_wind_dataset.py
python3 split_wind_dataset.py
python3 evaluate_models.py
python3 plot_predictions.py
python3 predict_next_hour.py
```

각 스크립트는 현재 작업 폴더에서 입력 CSV를 읽고 결과 파일을 같은 폴더에 저장합니다. 따라서 프로젝트 폴더에서 실행해야 합니다. `check_data.py`는 원본 상태를 확인하는 단계이며, 이후 스크립트는 앞 단계에서 생성한 파일을 입력으로 사용합니다.

## 9. 분석 결과 및 프로젝트 의의

실제 프로젝트 파일을 이용해 계산한 2024년 12월 테스트 결과:

| 모델 | MAE (m/s) |
|---|---:|
| Persistence | **0.6535** |
| Linear Regression | **0.5946** |

이 데이터와 분리 기준에서는 선형 회귀의 12월 MAE가 Persistence 기준 모델보다 낮았습니다. 이는 해당 테스트 기간에서의 비교 결과이며, 다른 기간이나 데이터에도 같은 성능이 보장된다는 의미는 아닙니다.

최종 예측 스크립트는 2024-12-31 23시의 실제 관측값(풍속 1.3 m/s, 1시간 전 풍속 0.7 m/s, 2시간 전 풍속 1.0 m/s, 기온 -1.4°C, 습도 56%)을 확인해 사용했고, 2025-01-01 00시의 풍속을 **1.3835 m/s**로 예측했습니다. 이 값은 모델의 예측 결과이며, 실제 관측값과 비교해 검증한 값은 아닙니다.

이번 작업을 통해 시간 누락과 결측값을 임의로 보정하지 않고 다루는 과정, 시간 순서를 보존한 학습·테스트 분리, 기준 모델과 회귀 모델의 동일 조건 평가, 그리고 시간에 맞춘 예측 입력값 구성을 연습할 수 있습니다.
